# Aulas de Desenvolvimento Front-End 🌐✨

Bem-vindo(a) ao meu repositório de estudos de **HTML, CSS e JS**!  
Aqui estão reunidos os exemplos e exercícios desenvolvidos durante as aulas de Front-End na faculdade.

## 📚 Conteúdo das Aulas
- **Aula 1 e 2**: Introdução ao **HTML**, aprendendo a sintaxe básica, estrutura de páginas e principais tags.
- **Aula 3**: Primeiros passos com **CSS**, explorando estilos, cores, fontes e organização visual.

## 📂 Estrutura
- **Exemplos base**: pequenos sites e exercícios práticos para treinar HTML e CSS.
- **Pastas de aula**: cada aula contém seus próprios exemplos e atividades (`Aula_2`, `Aula_3`, etc.).

## 🎯 Objetivo
Este repositório serve como registro da minha evolução em **desenvolvimento web** e como material de apoio para colegas que também estão aprendendo.  
O foco é **construir páginas simples em HTML** e depois **incrementar com estilos em CSS**, preparando o caminho para projetos maiores.
